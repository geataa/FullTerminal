# FullTerminal 1.2.0 — Persistent SFTP, Column Sorting, External Upload HUD & Windows Startup

**FullTerminal 1.2.0** overhauls SFTP browsing and external file uploads with a persistent interactive `ConPty` transport, clickable **column sorting** and **New File (`+ File`)** creation on both SFTP panes, reliable **session restoration** across system-tray exits, native **Launch at Windows Startup** integration across Settings, System Tray and all 16 languages, **2-key global Visor shortcuts**, DPI-aware dynamic button sizing across the UI, and updated embedded/static third-party libraries.

## Highlights

- **Persistent SFTP Session, Instant Navigation, Column Sorting & New File Creation**:
  - `RemoteSftpFileSystem` maintains a single persistent OpenSSH `sftp.exe` `ConPty` session per remote host instead of spawning a fresh SSH/TLS handshake for every directory click or file operation.
  - Event-driven `condition_variable` output signaling (0 ms wakeup, zero polling lag) and normalized 30-second directory caching make revisiting parent/recent directories instantaneous while uncached directories complete in a single SFTP round-trip.
  - **Clickable Column Sorting (`▲` / `▼`)** on both Local and Remote SFTP tables: sort ascending or descending by **Name**, **Modified Date** (chronological timestamp), **Size** (numeric byte size), or **Type / Permissions**, keeping `..` pinned at the top and folders grouped before files.
  - **New File (`+ File`) & New Folder (`+ Folder`) Modals**: create empty files and folders directly in Local or Remote SFTP panels (action bar and right-click context menu), fixing an input-mask bug that previously dismissed SFTP modals on the opening click frame.
- **External Drag & Drop Upload HUD & File Picker**:
  - Dragging single or multiple external files/folders from Windows Explorer onto the SFTP view or an SFTP tab—or using the **`📤 Upload...`** button and remote context menu—immediately opens the live **Transfer HUD Banner**.
  - Displays multi-file badge `(1/N)`, target remote directory, live transfer speed/ETA (`MB/s`), progress bar (with smooth indeterminate pulse before percentage output begins), and an inline **Cancel** button (`CancelActiveTransfer`).
  - Eliminated a background idle-render loop that previously redrew frames continuously after a transfer banner completed.
- **Session Restoration Across System Tray Quit & Restart**:
  - Enabled automatic session restoration by default (with one-time `sessionPolicyVersion` migration for older `settings.ini` files while preserving subsequent user changes).
  - Verifies daemon session liveness (`alive`) before reattaching so exited daemon sessions cleanly launch fresh shells/SSH tabs instead of closing on startup, and persists SFTP local/remote directories and connected SFTP hosts across restarts.
- **Launch at Windows Startup (`--startup`)**:
  - Toggle **Launch at Windows startup** in **Settings → Application** or directly from the **System Tray** right-click menu (fully localized across all 16 languages).
  - Registers `"<FullTerminal.exe>" --startup` under `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`, automatically redirects `System32`/`SysWOW64` working directories to `%USERPROFILE%`, and starts quietly hidden in Visor/Tray mode at sign-in so it never interrupts the desktop.
- **Visor 2-Key Global Shortcuts, Dynamic Button Sizing & UI Polish**:
  - Cleaned duplicate icon/arrow prefixes across all 16 language tables and screens (`↑ Upload`, `↓ Download`, `+ New Host`, `⚡ Import .ssh`, `● ACTIVE`, etc.) and added dynamic text-measured button widths with padded clipping/elision so labels never overflow across languages or DPI scales.
  - Added 2-key global Visor shortcut capture and low-level hook support (`Key1 + Key2` as well as `Modifier + Key`).
  - Disabled unsupported Split/Broadcast actions on SFTP and Database tabs; made session Error Overlays dismissible via `[✕]`, click, or `Esc`.
  - Added keyboard navigation (`Up`/`Down`, `Enter`, `Backspace`, `Tab`, `F2`, `Delete`, `F5`) and modal `Enter`/`Esc` handling in SFTP, cached local drive queries, and fixed root/drive double-slash path copying and the `Ctrl+Shift+M` drawer shortcut conflict.
- **Updated Embedded & Static Libraries**:
  - **SQLite** `3.54.0` → **`3.54.1`**
  - **PostgreSQL `libpq`** `18.6` → **`18.7`**
  - **FreeTDS (`db-lib`)** `1.5.19` → **`1.5.21`**
  - **zlib** `1.3.2` → **`1.4`**
  - **OpenSSL `3.6.5`** and **MariaDB Connector/C `3.4.11`** verified at latest upstream releases; CI SSH loopback test fixture updated to **`paramiko 5.1.0`**.

## Validation

- **20/20 automated Windows x64 CTest suites passed**, including real OpenSSH SFTP protocol verification over a single persistent session (`SessionConnectCount() == 1`), cached directory navigation, multi-file external `UploadFiles` HUD rendering, isolated Windows startup registry verification, SSH loopback (`paramiko 5.1.0`), ConPTY daemon reattach, MCP HTTP/policy, and database workspace suites.
- Single-binary portable build verified: executable name remains **`FullTerminal.exe`**, version **`1.2.0`** (Windows file metadata: **`1.2.0.0`**), statically linked with MSVC CRT and zero external non-OS DLL dependencies.
