# FullTerminal 1.2.0 (Debian / Ubuntu Linux x64) — Native OpenGL Terminal, SSH/SFTP Hub, Kubernetes & Database Workspace

**FullTerminal 1.2.0 (`v1.2.0-debian`)** brings the complete native C++20 FullTerminal experience to **Debian 12+ (Bookworm / Trixie)**, **Ubuntu 22.04 LTS / 24.04 LTS+**, and modern `.deb`-based Linux distributions (**Linux Mint 21/22**, **LMDE 6**, **Pop!_OS 22.04+**, **Pardus 23+**, **Kali Linux**) with hardware-accelerated **OpenGL 32-bit ARGB** rendering, **FreeType2 / Fontconfig** crisp typography + color emoji fallback, **Herdr BSP split panes**, **Quake / Visor drop-down console**, **persistent background PTY daemon**, **SSH & persistent SFTP explorer**, **Kubernetes cluster switcher**, **statically linked native SQL workspaces**, and **11-tool MCP multi-agent orchestration**.

## Supported Linux Distributions

- **Direct `.deb` & `AppImage` Compatibility (`GLIBC >= 2.34`, `libstdc++6 >= 12`, `x86_64` / `amd64`)**:
  - **Debian**: Debian 12 (*Bookworm*), Debian 13 (*Trixie* / *Testing* / *Sid*)
  - **Ubuntu**: Ubuntu 22.04 LTS (*Jammy*), Ubuntu 24.04 LTS (*Noble*), and newer releases
  - **Debian / Ubuntu Derivatives**: Linux Mint 21 & 22, LMDE 6, Pop!_OS 22.04+, Pardus 23+, Kali Linux, Zorin OS 17+, elementary OS 7+
- **Desktop Environments & Window Managers**:
  - Works across **GNOME (Mutter X11 & Wayland/XWayland)**, **KDE Plasma (KWin)**, **XFCE**, **Cinnamon**, and **MATE** using standard EWMH atoms, 32-bit ARGB GLX visual selection, and XInput2 raw global shortcut listeners.
- **Older Distributions (Debian 11 *Bullseye* and earlier)**:
  - Prebuilt binaries target `glibc 2.34+`; older releases can build directly from the `debian` branch source (`make -j$(nproc)`).

## Highlights in 1.2.0 (Debian / Linux Edition)

- **Hardware-Accelerated OpenGL + FreeType2 / Fontconfig Engine & Desktop Transparency**:
  - 32-bit ARGB `GLXFBConfig` visual selection enables real desktop alpha transparency (**10% – 100% opacity**) across normal, maximized, and Quake/Visor windows on composited desktops (including GNOME/Mutter), keeping text, cursor, SFTP views, and modals crisp and fully legible.
  - Dynamic Fontconfig resolution automatically selects clean system UI & monospace fonts (`Ubuntu` / `Cantarell` / `Noto Sans` / `DejaVu Sans` and `JetBrains Mono` / `Ubuntu Mono` / `DejaVu Sans Mono`) with full **Noto Color Emoji** glyph fallback.
  - Borderless 8-way window edge/corner resizing (`_NET_WM_MOVERESIZE`), bottom-right statusbar resize grip, and dock/panel-aware maximization (`_NET_WORKAREA` and GNOME `_GTK_WORKAREAS_D*`).
- **Quake / Visor Drop-Down Console, Global Hotkeys & Parametric Focus Behavior**:
  - XInput2 raw keyboard listener (`XI_RawKeyPress` / `XI_RawKeyRelease`) supports single-key (`F12`), modifier+key, and **2-key global Visor shortcuts** across any focused desktop window, including full **Turkish Q** and international XKB layout Punctuation/OEM key translation.
  - Flicker-free interactive bottom-edge Visor resizing (`NorthWestGravity` + synchronous frame presentation).
  - Parametric **Auto-hide when focus is lost** toggle (`On (Auto-hide)` / `Off (Stay pinned)`) configurable from **Settings → Visor**, **Settings → Application**, and the **Quick Slide Drawer**.
- **Herdr BSP Split Panes, Standard Terminal Shortcuts & Persistent Tab Titles**:
  - Split any terminal tab vertically (`Ctrl+Shift+D`) or horizontally (`Ctrl+Shift+E`), zoom active panes (`Ctrl+Shift+Z`), and broadcast keystrokes (`Ctrl+Shift+I`).
  - Full xterm/readline modifier encoding & native Linux keyboard integration: **`Ctrl+Left`/`Ctrl+Right`** and **`Alt+Left`/`Alt+Right`** word jumping, **`Ctrl+Backspace`** and **`Ctrl+Delete`** word deletion, **`Ctrl+/`** undo, **`Home`/`End`** normal + application cursor mode (`DECCKM`), **`Ctrl+Insert`/`Shift+Insert`** copy/paste, **`Ctrl++`/`Ctrl+-`/`Ctrl+0`** font zoom, **`Shift+PageUp/PageDown/Home/End`** scrollback navigation, and XIM UTF-8 (`Xutf8LookupString`) input for Turkish (`ğ`, `ş`, `ı`, `İ`, `ö`, `ü`, `ç`) and international layouts.
  - Tab-level title preservation ensures custom tab names (and primary session titles) are never overwritten when splitting panes, cycling pane focus, closing the initial pane, or restoring saved sessions.
- **Background POSIX PTY Session Daemon & Launch on Startup**:
  - `fullterminal --daemon` keeps live shell and SSH sessions running in the background over an authenticated `0600` UNIX domain socket (`session.sock`), replaying up to 256 KiB of recent output on GUI reattach and automatically recovering from stale sockets if the daemon was terminated externally.
  - Native **Launch on Startup** (`~/.config/autostart/fullterminal.desktop` with `--startup`) across all 16 UI languages.
- **SSH Hub, Persistent SFTP Explorer & Kubernetes Active-Cluster Manager**:
  - OpenSSH integration with **HMAC-SHA1 `HashKnownHosts`** host-key verification (standard on Ubuntu/Debian `~/.ssh/known_hosts`), jump-host support, and persistent interactive `sftp` sessions with column sorting (`▲` / `▼`), `+ File` / `+ Folder` creation, and live upload progress HUD.
  - Multi-file Kubernetes YAML / kubeconfig import (`zenity` / `kdialog` native multi-select picker), scrollable cluster popup menu, persistent active-cluster selection, and clean **single-file `KUBECONFIG` export** so switching clusters exports only the selected YAML rather than concatenating every file in `~/.config/fullterminal/k8s/`.
- **Statically Linked Native Database & SQL Workspaces**:
  - Zero external database client `.so` packages required: **SQLite 3.54.1**, **PostgreSQL `libpq` 18.7**, **MariaDB Connector/C 3.4.11**, **FreeTDS (`db-lib`) 1.5.21**, **OpenSSL 3.6.5**, and **zlib 1.4** are compiled and linked statically into the `fullterminal` binary.
  - Includes the 4-mode TLS selector (**Auto / Prefer**, **Disabled**, **Require (Self-signed)**, **Verify CA**), default PostgreSQL database resolution, live schema filter, in-place database switching, parameterized table CRUD, and CSV/JSON export.

## Downloads and Installation

- **`fullterminal_1.2.0_amd64.deb`** — Native Debian / Ubuntu installer package (adds application binary `/usr/bin/fullterminal`, desktop launcher, and HiDPI icons):
  ```bash
  sudo apt install ./fullterminal_1.2.0_amd64.deb
  ```
- **`FullTerminal-1.2.0-x86_64.AppImage`** — Single-file portable Linux executable (no installation required):
  ```bash
  chmod +x FullTerminal-1.2.0-x86_64.AppImage
  ./FullTerminal-1.2.0-x86_64.AppImage
  ```
- **`FullTerminal-1.2.0-linux-x64-portable.tar.gz`** — Self-contained portable directory archive storing all configuration and sessions inside an adjacent `portable_data/` folder.
- **`fullterminal`** — Standalone `x86_64` ELF binary with statically linked database & TLS engines.
- **`SHA256SUMS.txt`** — SHA-256 checksums for all Debian / Linux release artifacts.
